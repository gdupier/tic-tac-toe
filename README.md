# Tic Tac Toe

A self-contained Tic Tac Toe game that runs in any web browser — no installation, no dependencies. Just open `tic-tac-toe.html`.

## Features

- **Two-player mode** — play locally against a friend, X vs O.
- **Single-player mode** — play against the computer with three difficulty levels:
  - **Easy** — random moves.
  - **Medium** — plays optimally ~60% of the time.
  - **Hard** — unbeatable AI powered by the [minimax](https://en.wikipedia.org/wiki/Minimax) algorithm.
- **Scoreboard** tracking X wins, O wins, and draws across rounds.
- **Winning line highlight** and clear turn/result status messages.

## How to play

Double-click `tic-tac-toe.html` (or open it in your browser). Pick a mode at the top, then click a cell to make your move.

## Tech

Plain HTML, CSS, and JavaScript in a single file. No build step required.
